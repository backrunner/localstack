从 **0.2.3-beta.2** 起，LocalStack 内置原生更新器。已安装的签名发行版会从同一 GitHub 仓库检查更新，无需额外安装工具。

## 选择通道

| 通道 | 接收的版本 |
| --- | --- |
| Stable（正式版） | 更新的正式发布版本 |
| Beta | 更新的 Beta，以及更新的正式版本 |

首次安装 Beta 默认选择 Beta 通道。你可以在设置中更改，之后不会因为安装了其他版本而自动改变选择。

切换通道不会降级。例如从较新的 Beta 切换到 Stable 时，应用会等待版本号更高的正式版本。

## 检查与安装

1. 应用在后台按每个通道至多每 24 小时检查一次。也可以在设置里手动检查。
2. 默认自动下载可用更新；关闭自动下载后，应用仍会检查并提示新版本。
3. 下载后校验包大小、SHA-256、签名、公证和版本信息。
4. 你点击「重启并更新」后，应用才执行替换并重新启动。

正常退出不会自动安装更新。更新流程不会终止你启动的开发服务器。

## 从 beta.1 迁移

`0.2.3-beta.1` 没有内置更新器，无法自动获得新版本。请从 [下载页面](/docs) 手动安装一次当前版本，之后即可使用应用内更新。

## 更新失败时

检查网络是否能够访问 GitHub，确认安装位置对当前用户可写。GitHub API 限流时应稍后重试，手动检查之间至少间隔 60 秒。签名、校验和或安装验证失败时，不要绕过验证；可以在 [GitHub Issues](https://github.com/backrunner/localstack/issues) 报告问题。

开发者可以阅读仓库中的 [更新器实现与验证说明](https://github.com/backrunner/localstack/blob/main/docs/auto-updates.md)。
