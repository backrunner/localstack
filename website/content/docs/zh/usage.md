点击菜单栏中的 LocalStack 图标即可打开面板。列表显示已经验证且处于活跃状态的服务，每个服务一行，不再区分自动发现与主动注册来源。一屏最多显示 8 行，更多服务通过带边缘渐隐的列表滚动查看。

## 找到并打开站点

搜索框支持按名称、URL、端口或项目路径筛选。点击服务的打开按钮，会在默认浏览器中打开已验证的 URL。服务菜单还提供复制地址和查看详情等操作。

| 快捷键 | 操作 |
| --- | --- |
| `⌘ F` | 聚焦面板内的搜索框 |
| `⌘ R` | 刷新服务列表 |
| `Return` | 搜索框中打开首个结果，或在列表中打开选中的服务 |
| `Delete` | 为选中的服务发起停止确认 |

这些快捷键在 LocalStack 面板获得焦点时生效。

## 停止服务

每行直接提供停止按钮，也可以进入选择模式，多选后批量停止。确认信息列出受影响的服务和进程；同一进程对应的多个端口会合并处理。Coordinator 在实际操作前重新验证进程身份、用户、启动时间与端口归属。

常规停止使用 `SIGTERM`。如果进程没有响应，可以进一步选择强制停止；强制操作需要单独确认。校验不通过的服务不会被终止。已关闭的监听端口会立即从列表移除，即使进程仍在清理；部分失败时，仍在运行的服务会保留，并显示失败信息。延迟的强制停止确认不会作用于复用 PID 的新进程。

## 原生外观

应用使用 SwiftUI 与 AppKit，跟随 macOS 的深色和浅色外观。macOS 26 使用 Liquid Glass，macOS 15 使用系统材质。菜单栏图标同样跟随系统外观变化。

GitHub DMG 只包含菜单栏应用与内嵌 Coordinator，**不包含独立 CLI 或 Widget 扩展**。WidgetKit 代码是独立 Xcode 目标，不是当前下载包提供的功能。应用支持 `localstack://` 服务深链路。

## 设置与更新

在面板底部打开设置，可以管理登录启动和应用更新。已安装的签名版本会在后台检查更新；安装需要你点击「重启并更新」。详见 [自动更新](/docs/updates)。
